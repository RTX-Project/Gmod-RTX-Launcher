# Project Key Decisions & Architecture

## Архитектурные решения
- **Главное окно и Авто-масштабирование (Auto High-DPI Scaling)**: UI создаётся в `ImGui::Begin("RTX Launcher", ...)` с флагами `NoDecoration | NoMove | NoSavedSettings | NoResize`. Приложение автоматически определяет разрешение экрана (`CalculateUiScale`) и адаптирует размеры окна (`860×500` на Full HD, пропорционально масштабируется на 2K/4K) и глобальный масштаб шрифтов/элементов (`io.FontGlobalScale = g_uiScale`).
- **Интерфейс в стиле macOS (Sidebar Navigation & Window Controls)**:
  - Левая боковая панель шириной 240px содержит навигацию («Главная», «Настройки», «Моды»).
  - Кнопки управления окном (Закрыть — красная, Свернуть — жёлтая) отрисовываются вручную через `ImDrawList` с эффектами наведения (иконки x и -) поверх `ImGui::InvisibleButton`.
  - Модифицирован перехватчик `WM_NCHITTEST` (исключена зона `pt.x <= 70`), чтобы системный drag-and-drop окна не блокировал клики по кнопкам macOS в левом верхнем углу.
- **Модульная архитектура UI (Refactored `RenderImGuiUI`)**: Монолитный блок отрисовки в `main.cpp` разбит на отдельные файлы (`UI_Overview.cpp`, `UI_Settings.cpp`, `UI_RtxMods.cpp` и т.д.), что сильно упростило поддержку кода и решило проблемы с областью видимости.
- **6-шаговый Мастер Первого Запуска (Setup Wizard)**: Пошаговый сценарий установки (`Welcome` -> `RtxPreset` -> `LaunchMode` -> `DriveSelect` -> `Progress` -> `Complete`) с обязательным явным выбором вариантов (блокировка кнопок «Далее»), анимацией смещения страниц справа налево в стиле фирменных переходов лаунчера и выбором («Играть сейчас» / «Позже») по завершении.
- **Детектор Видеокарт (GPU Detection & Hardware Compatibility)**: Через DXGI опрашивается модель видеокарты (`g_app.gpuInfo = DetectGPU()`). Для карт NVIDIA RTX выводится статус полной совместимости. Для карт AMD Radeon RX, Intel Arc/Iris и устаревших NVIDIA GTX выводится предупреждающий баннер на главной странице и в настройках о том, что полная производительность и стабильность RTX Remix на этой архитектуре не гарантируется.
- **Страница «Обновления и Чейнджлог» (`Page::Updates`)**: Постоянный полноразмерный раздел лаунчера, открываемый по кнопке «Обновления» с главной страницы. Показывает текущий билд лаунчера, статус релизов на GitHub, скроллируемый блок чейнджлога (`releaseNotes` напрямую с GitHub API) и кнопку «СКАЧАТЬ И УСТАНОВИТЬ ОБНОВЛЕНИЕ».
- **Интеллектуальный Модуль Авто-Обновлений (`LauncherUpdater`)**:
  - Всеядный парсер номеров сборок `ParseBuildNumber` (извлекает наибольшее число из тега релиза, напр. `v0.0.107-alpha` ➔ `Build 107`).
  - Опрос GitHub API через WinHTTP с явным включением протоколов `TLS 1.2` и `TLS 1.3` (`WINHTTP_OPTION_SECURE_PROTOCOLS`).
  - Поддержка пре-релизов (`INCLUDE_PRERELEASES = true`), fallback на любые прикрепленные файлы ассетов (`.exe`, `.zip`), поддержка GitHub Personal Access Token для закрытых репозиториев.
  - Бесшовное авто-обновление в 1 клик с фоновой поддержкой батника командной строки для горячей замены исполняемого файла.
  - Автоматическая опросная проверка обновлений раз в 5 часов в фоновом потоке, когда лаунчер открыт на главном экране.
- **Адаптивный градиент прогресс-бара (`GetAdaptiveProgressColor`)**: Прогресс-бар динамически меняет расцветку по мере выполнения: от ярко-красного (0%) через солнечно-жёлтый (50%) к насыщенному ярко-зелёному (100%).
- **Оптимизация под Высокочастотные Мониторы (165Hz High Refresh Rate)**: Учёт состояния `g_wizardIsSliding` в `IsAnimationActive` и снятие искусственных задержек VSync (`Present(0,0)`) при активных анимациях обеспечивает сверхплавную регенерацию кадров на мониторах 144Hz / 165Hz / 240Hz.
- **Экран проверки обновлений при старте**: Текст «Проверка на наличие обновлений...» дожидается полного завершения асинхронной проверки GitHub перед переходом на главную страницу.
- **Быстрый запуск и Инкрементальная проверка**: При первичном запуске лаунчер выполняет полную копию файлов (7 ГБ), извлекает DXVK RTX, применяет патчи и загружает фиксы. При всех повторных запусках тяжёлый процесс копирования пропускается.
- **Инсталлятор `rtx-installer` (Автономный установщик)**: 
  - Отдельный C++ ImGui проект для загрузки и распаковки портативной сборки игры. 
  - Имеет общий визуальный стиль с основным лаунчером (тёмный градиент, скругленные полупрозрачные карточки `ImGui::BeginChild` без стандартных рамок, кнопки macOS для управления окном).
  - Вкомпилирована правильная иконка приложения `app_icon.ico` через `rtx-installer.rc`.
  - Динамический цвет прогресс-бара и кнопки с логикой наведения.
- **Детализация Шрифтов (Oversampling)**: Для повышения четкости шрифтов на экранах высокого разрешения в конфигурации `ImFontConfig` включены флаги `OversampleH = 4`, `OversampleV = 4` и `PixelSnapH = true`. Это полностью устраняет «мыло» и пиксельные лесенки в ImGui.

## Правила Разработки (Development Rules)
- **Инкремент билдов (Build Incrementing)**: ПРИ КАЖДОМ новом билде / компиляции лаунчера обязательно увеличивать константу `CURRENT_BUILD_NUMBER` на 1 (даже если билд оказался неудачным), чтобы избежать путаницы с версиями.
- **Кодировка UTF-8 (Cyrillic Strings)**: При редактировании файлов (особенно `main.cpp`), содержащих кириллицу (например, названия кнопок «Главная», «Настройки»), всегда сохранять файл в строгой UTF-8 кодировке во избежание Mojibake (кракозябр).
