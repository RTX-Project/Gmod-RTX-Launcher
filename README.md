## 🌟 Зачем нужен Garry's Mod RTX Launcher?

Установка графических модов и трассировки лучей для старых игр на движке Source требует ручной перетасовки файлов, поиска нужных библиотек и постоянных настроек. **Наш лаунчер берет всю рутину на себя:**

- ⚡ **Запуск в один клик**: Нажмите кнопку «Запуск» — лаунчер сам подготовит Garry's Mod и включит трассировку лучей.
- 🧙‍♂️ **Пошаговый мастер установки**: Простой помощник из 4 шагов при первом запуске — сам найдет игру и установит все нужные RTX-фиксы.
- 🔄 **Автоматические обновления**: Лаунчер сам проверяет и скачивает свежие улучшения освещения (ассеты) и собственные обновления.
- ⚙️ **Встроенные патчи**: Автоматически исправляет известные проблемы совместимости Garry's Mod и RTX Remix.

---

## 🎮 Как начать пользоваться?

1. **Скачайте** актуальную версию лаунчера из релизов.
2. **Запустите файл `RTX-Launcher.exe`**.
3. Пройдите простой **Мастер первого запуска** (укажите папку с установленным Garry's Mod, если она не найдена автоматически).
4. Нажмите **«Запуск»** и наслаждайтесь реалистичной графикой с трассировкой лучей!
