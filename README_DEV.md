# 🛠 Руководство Разработчика (Gmod-RTX-Launcher)

Этот файл создан специально для вас, чтобы вы всегда знали, где находится нужный код, как выпустить обновление и где менять текст на сайте, не прибегая к помощи ИИ каждый раз.

---

## 📂 1. Структура проекта (Где что лежит)

Ваш проект разделен на три главные части: **Лаунчер**, **Инсталлятор** и **Сайт**.

### 🎮 Лаунчер (`rtx-launcher/`)
Здесь находится весь исходный код C++ интерфейса (ImGui).
* `main.cpp` — Точка входа. Здесь настраивается окно, верхняя панель (кнопки закрыть/свернуть) и боковое меню.
* `UI_Overview.cpp` — Главная страница лаунчера (кнопка "Запустить", статистика диска).
* `UI_Settings.cpp` — Вкладка "Настройки" (пути, параметры запуска, включение/выключение RTX).
* `UI_RtxMods.cpp` — Вкладка "Моды". Здесь лаунчер парсит ModDB и качает архивы.
* `LauncherUpdater.h` — Скрипт авто-обновления. **Здесь меняется версия лаунчера**!
* `Theme.h` — Все цвета, отступы и шрифты интерфейса.

### 📦 Инсталлятор (`rtx-installer/`)
* `main_installer.cpp` — Код автономного распаковщика портативной сборки (с прогресс-баром).

### 🌐 Сайт лаунчера (`docs/`)
Сайт автоматически работает через GitHub Pages. Любые изменения в этой папке обновляют сайт через 2-3 минуты после коммита.
* `docs/index.html` — Весь текст сайта (FAQ, фичи, карточки). Откройте его в блокноте, нажмите `Ctrl+F` и меняйте любой текст.
* `docs/style.css` — Цвета и дизайн сайта.
* `docs/images/` — Картинки.
  * `rtx_on.jpg` и `rtx_off.jpg` — Картинки для слайдера "ДО / ПОСЛЕ". Хотите их заменить? Просто закиньте сюда новые картинки с такими же названиями (главное, делайте скриншоты в игре, не двигая мышку!).

## 🚀 2. Как выпустить новую версию лаунчера

Чтобы игроки получили автоматическое обновление, вам нужно сделать всего **3 простых шага**:

1. **Измените версию в коде:**
   Откройте `rtx-launcher/LauncherUpdater.h`. Найдите строки (примерно 16-17 строчка):
   ```cpp
   inline static const std::wstring CURRENT_VERSION = L"0.0.2.6.4";
   inline static const int CURRENT_BUILD_NUMBER = 245;
   ```
   Увеличьте версию (например, на `0.0.2.6.5`) и номер билда (на `246`). Сохраните файл.

2. **Отправьте код на GitHub (Commit & Push):**
   Зафиксируйте изменения и отправьте их в ветку `main`.

3. **Создайте Релиз (Tag):**
   Зайдите на GitHub в раздел **Releases** -> **Draft a new release**.
   В поле **Tag** напишите вашу новую версию с буквой "v" в начале (например, `v0.0.2.6.5`). Напишите патчноут и нажмите **Publish**.
   *Всё! GitHub Actions (вкладка Actions) сам скомпилирует `system_data.bin` и `rtx-installer.exe` и прикрепит их к вашему релизу.*

## 🔗 3. Ссылки на скачивание (Плейсхолдеры)

Вам больше **не нужно** вручную менять ссылки на скачивание на сайте при каждом новом релизе!

`https://github.com/RTX-Project/Gmod-RTX-Launcher/releases/latest/download/rtx-installer.exe`

Эта ссылка **автоматически** берет файл из самого свежего стабильного релиза, который вы опубликовали.

## 🤖 4. Автоматическая сборка (GitHub Actions)

В папке `.github/workflows/` лежат скрипты автоматики:
* `release.yml` — Запускается **только тогда**, когда вы создаете новый тег (релиз), начинающийся на `v` (например, `v1.0`). Он собирает чистовую (Release) версию лаунчера и инсталлятора без дебаг-консоли.
* `build-beta.yml` — Запускается при **каждом коммите**. Он компилирует лаунчер в режиме Debug, чтобы вы могли проверять ошибки, и автоматически прикрепляет бета-билд к скрытому релизу `beta-build`.
