# 🛠 Полное Руководство Разработчика (Gmod-RTX-Launcher)

Данный документ — максимально подробная техническая шпаргалка по устройству репозитория, логике работы компонентов и местоположению всех хардкодов и плейсхолдеров проекта.

---

## 📂 1. Детальная архитектура и структура файлов

Проект разделен на три независимых модуля:
1. Основной Лаунчер (C++, ImGui, DirectX 11).
2. Автономный Инсталлятор (C++, ImGui).
3. Веб-сайт (HTML, CSS, JS, GitHub Pages).

### 🎮 Модуль 1: Основной Лаунчер (`rtx-launcher/`)
Лаунчер отвечает за проверку и скачивание обновлений, управление модами и запуск игры с инжектором RTX Remix.
* **`main.cpp`** (Ключевой контроллер окна)
  * Находится логика Win32 окна, перехват сообщений `WM_NCHITTEST` для кастомного управления окном в стиле macOS.
  * Здесь же прописан `ImGui::Begin("RTX Launcher")` и отрисовывается левое навигационное меню (Sidebar).
  * Настроено авто-масштабирование (`io.FontGlobalScale`) под High-DPI экраны (4K/2K).
* **`UI_Overview.cpp`** (Главный экран)
  * Отрисовка основной карточки "Garry's Mod + RTX" и статуса "Готов к запуску".
  * Логика прогресс-бара скачивания обновлений игры/лаунчера.
* **`UI_Settings.cpp`** (Экран настроек)
  * Управление путями установки, включение/отключение RTX Remix, очистка кэша RTX (`.rtx` файлов) и кнопка принудительного обновления.
  * В этом же файле лежат `ShellExecute` вызовы для кнопок-ссылок (на Discord, GitHub и т.д.).
* **`UI_RtxMods.cpp`** (Вкладка управления модами)
  * Интерфейс библиотеки модов (карточки модов).
  * Связан с классом парсера для скачивания с ModDB.
* **`ModDBScraper.cpp / .h`** (Парсер модов)
  * Модуль, который в фоновом скрытом окне WebView2 или через WinHTTP парсит страницу ModDB, ищет кнопку `Download` и скачивает `zip` архивы модов в папку игры в обход лимитов GitHub Releases.
* **`LauncherUpdater.h`** (Система автообновлений)
  * Обращается к GitHub API `https://api.github.com/repos/RTX-Project/Gmod-RTX-Launcher/releases`.
  * Использует WinHTTP с принудительными флагами `TLS 1.2` и `TLS 1.3`.
  * Реализован `.bat` механизм самозамены (hot-swap). Если `rtx-launcher.exe` заблокирован антивирусом при попытке перезаписи, батник уходит в цикл ожидания (`timeout /t 1`), пока блокировка не снимется.
* **`HttpClient.h`**
  * Универсальная обёртка над WinHTTP для работы с сетью во всех остальных модулях.
* **`Theme.h` / `Globals.h` / `AppLogic.h`**
  * `Theme.h`: Цветовая палитра ImGui, скругления (`FrameRounding`), шрифты (Oversampling H/V = 4 для 4K мониторов).
  * `Globals.h`: Глобальные переменные состояния UI (анимации слайдера, текущая страница).
  * `AppLogic.h`: Внутренняя бизнес-логика и пути.

### 📦 Модуль 2: Инсталлятор (`rtx-installer/`)
Автономная мини-программа для первичной установки портативной сборки (Portable build).
* **`main_installer.cpp`**
  * Минималистичный UI, похожий на основной лаунчер, но состоящий из одного экрана загрузки.
  * Динамический цвет прогресс-бара от красного к зеленому по мере завершения распаковки.
* Имеет свою иконку через `rtx-installer.rc`.

### 🌐 Модуль 3: Веб-Сайт (`docs/`)
Сайт автоматически разворачивается на серверах GitHub (GitHub Pages) при пуше в `main`.
* **`docs/index.html`**
  * Весь текстовый контент сайта, структура блоков "Возможности", "Установка", "FAQ" и слайдер "ДО/ПОСЛЕ".
* **`docs/style.css` & `docs/script.js`**
  * Стилистика (тёмная тема, неон) и анимации при скролле.
* **`docs/images/`**
  * `rtx_on.jpg` и `rtx_off.jpg` — полноразмерные (3440x1440 и выше) скриншоты для слайдера.

## 🔍 2. Карта Плейсхолдеров и Хардкодов (Где что менять)

### [В КОДЕ ЛАУНЧЕРА]
1. **GitHub Репозиторий и Владелец (Откуда идут обновы):**
   * **Файл:** `rtx-launcher/LauncherUpdater.h` (Строки ~16-20)
   * **Переменные:** 
     `REPO_OWNER = L"RTX-Project";`
     `REPO_NAME = L"Gmod-RTX-Launcher";`
2. **Версия и Билд лаунчера:**
   * **Файл:** `rtx-launcher/LauncherUpdater.h` (Строки ~16-17)
   * **Переменные:** 
     `CURRENT_VERSION = L"0.0.2.6.4";`
     `CURRENT_BUILD_NUMBER = 251;`
3. **Ссылки на моды (ModDB):**
   * **Файл:** `rtx-launcher/main.cpp` (Строка ~1425)
   * **Переменная:** 
     `moddbProjectUrl = L"https://www.moddb.com/mods/metrostroi-rtx";`
     *Если мод переехал на другую страницу, менять нужно именно этот URL!*
4. **Тексты и названия вкладок (Русская локализация UI):**
   * **Где искать:** Откройте файлы `main.cpp`, `UI_Overview.cpp`, `UI_Settings.cpp`.
   * **Как выглядит:** Тексты зашиты прямо в функции вызова кнопок и текста (например: `ImGui::Text("Готов к запуску");` или `ImGui::Button("Настройки");`). Изменяйте текст прямо внутри кавычек. Важно: файл должен быть сохранен в кодировке **UTF-8**, иначе вместо русского текста будут кракозябры.

### [НА ВЕБ-САЙТЕ]
1. **Любой текстовый контент сайта:**
   * **Файл:** `docs/index.html`
   * Все карточки преимуществ, заголовки, ЧаВо (FAQ) — находятся там. Откройте в редакторе, нажмите `Ctrl+F` для поиска старого текста и замените на новый.
2. **Кнопки "Скачать":**
   * **Файл:** `docs/index.html`
   * Ссылки на кнопках скачивания теперь **ДИНАМИЧЕСКИЕ**. Они ведут на:
     `https://github.com/RTX-Project/Gmod-RTX-Launcher/releases/latest/download/rtx-installer.exe`
     *Вам больше не нужно их трогать при выходе новых патчей! GitHub сам отдаст самый свежий файл из стабильного релиза.*
3. **Скриншоты для слайдера ДО/ПОСЛЕ:**
   * **Файлы:** `docs/images/rtx_on.jpg` и `docs/images/rtx_off.jpg`
   * Замените файлы в этой папке. Обязательное правило: делайте скриншоты в игре **СТРОГО с неподвижной камерой** (убрав руки от мышки, просто нажимая кнопку включения/выключения RTX), чтобы картинки идеально совпадали пиксель-в-пиксель.

## 🚀 3. CI/CD: Релизы и Автоматика (GitHub Actions)

Весь процесс компиляции и релизов автоматизирован скриптами в папке `.github/workflows/`:

### 🛠 `build-beta.yml` (Бета-сборки)
* **Когда запускается:** При **любом** сохранении кода (коммит и пуш в `main`).
* **Что делает:** Компилирует проект в режиме `Debug` (чтобы вы могли видеть ошибки в консоли) и автоматически заливает `system_data.bin` в **скрытый** релиз на GitHub под названием `beta-build`.
* **Зачем нужен:** Чтобы тестеры и разработчики могли мгновенно получать самую свежую версию лаунчера после каждого изменения кода.

### 🌟 `release.yml` (Стабильные сборки)
* **Когда запускается:** Только тогда, когда вы создаете новый **Тег** (Tag), начинающийся с буквы `v` (например, `v0.0.2.6.5`).
* **Что делает:** 
  1. Автоматически парсит файл `LauncherUpdater.h` и увеличивает `CURRENT_BUILD_NUMBER` на +1.
  2. Компилирует проект строго в режиме `Release` (чистая, оптимизированная сборка без дебаг-консоли).
  3. Собирает оба файла: `rtx-installer.exe` и `system_data.bin`.
  4. Прикрепляет их к вашему релизу на странице GitHub Releases, делая доступными для скачивания всем пользователям сайта по кнопке "Скачать".

### 📝 Пошаговый план выпуска обновления:
1. Зайдите в `LauncherUpdater.h` и повысьте версию в переменной `CURRENT_VERSION` (например с `0.0.2.6.4` на `0.0.2.6.5`).
2. Сохраните и запушьте коммит на GitHub (`git commit`, `git push`).
3. Зайдите на сайт GitHub в ваш репозиторий -> Раздел **Releases** -> **Draft a new release**.
4. Нажмите `Choose a tag` -> Впишите `v0.0.2.6.5` -> Нажмите **Create new tag**.
5. Напишите красивый патчноут (что нового) и нажмите зеленую кнопку **Publish release**.
6. Идите пить чай (GitHub Actions сам всё скомпилирует в течение 2-3 минут и добавит `.exe` и `.bin` файлы прямо в этот релиз). Игроки получат авто-обновление мгновенно!
